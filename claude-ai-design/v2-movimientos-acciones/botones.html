Botones: one system for all of v2

Seven types, three sizes, four states. They follow the v2 rule black = tap, color = state. Red is the only color a button can have, because it announces a state: what you're about to do can't be undone or ends something. Everything is tokens from mobile/v2/tokens, so Oliva/Nítido and light/dark come for free (both modes shown below).

Sizes and states

SizeHeightWhere
L50The screen's or sheet's main action (Guardar, Listo)
M44Actions inside the page or a card (Registrar pago, Cerrar sesión, Agregar)
S32 (+ hitSlop up to 44)Selectors and chips

States: pressed (scale .98, opacity .85) · disabled (fill sunk, text control; never just a lower opacity) · loading (spinner + the label stays, so the button doesn't change size). Labels are a verb or an outcome ("Guardar", "Sí, borrar todo"), never "OK" or "Aceptar".

What changes in the mockups

  • Ajustes: "Cerrar sesión" goes from quiet text to destructivo. In Privacidad, "Borrar todo" too (its confirmation uses the red fill).
  • Mis cuentas: a future "Archivar cuenta" will be destructivo; "Editar cuenta" stays texto.
  • Detalle: "No es un movimiento" stays texto, because it has Deshacer for 5 s.
  • Destinatario sheet: Renombrar / Unir / "Es una persona" stay texto; Registrar pago is primario, Recordarle secundario.
  • In code: one Button component in mobile/v2/components with variant (primary · secondary · text · destructive) and size (L · M · S), plus Chip, Segmented, IconButton. Each screen uses these, never a loose style.
