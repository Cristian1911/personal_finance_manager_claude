# Handoff a Claude Design — Experiencia guiada de Zeta

Paquete de insumos para que Claude Design plantee el diseño de la experiencia guiada. Claude Design ya tiene el design system integrado; aquí va el contexto que le falta.

## Contenido
| Archivo | Qué es |
|---|---|
| **`00-PROMPT.md`** | El prompt a pegar en Claude Design. **Empieza aquí.** |
| `01-objetivos.md` | Objetivos, valor central, restricciones, entregables, métricas. |
| `02-funcionalidades.md` | Capacidades + matriz de activación + set mínimo de datos + las 4 rampas de entrada. |
| `03-pantallazos/` | `actual/` (18 capturas del estado actual) + `concepto/` + `INDEX.md` (dónde ancla cada guía). |
| `04-brief-estrategia.md` | Estrategia completa: mapa de capacidades, cohesión onboarding, simplificaciones, matriz de ubicación de guía. |

## Concepto interactivo
`../guided-experience-mockup.html` (servido en `localhost:4555`) — mockup navegable: Mapa de capacidades · Onboarding→Home · Patrones de guía · Rampas de entrada.

## Cómo usarlo
1. Abre `00-PROMPT.md`, cópialo a Claude Design.
2. Adjunta `01`, `02`, `04` y la carpeta `03-pantallazos/`.
3. Pídele Fase 1 primero (chooser + "Primeros pasos" + EmptyState) — máximo impacto.
