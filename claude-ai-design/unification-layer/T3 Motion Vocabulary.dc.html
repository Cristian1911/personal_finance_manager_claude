3a Zeta · unification layer · T3

Motion vocabulary

One idiom: the disclosure. Everything that expands in Zeta expands the same way — same wording, same caret, same curve, same 160ms. Motion exists for spatial context only; transform and opacity are the whole budget. And one hard rule ends the dimming drift: the page dims only when input focus leaves it. Expanding is reading, not a mode. The demos below are live — click them (Tweaks: “cámara lenta” slows everything 6× for inspection).

a · la revelación — anatomía
AFFORDANCE “Ver + qué” — the label always names what will appear: “Ver flujo por día”, “Ver desglose”, “Ver 7 categorías”. Expanded, it re-labels to “Ocultar”. Never bare “Ver”. 12px / 600 sage-light, hover white, ≥44px hit area. Never brass — brass stays on primary actions. CARET Chevron-down, 12px, stroke 1.5, right of the label. Rotates 180° on expand on the same curve. It is the only element in the app that rotates. CONTAINER Grid rows 0fr → 1fr, 160ms — no JS measuring, no max-height hacks. Content enters at 120ms opacity + 3px translateY: the existing page-enter grammar, reused. Siblings reflow; nothing springs, scales, or slides sideways. EASING One curve for everything: cubic-bezier(0.2, 0, 0, 1). Decisive start, soft landing. No bounce, no overshoot. DURATIONS Three, total: 120 content-enter · 160 disclosure · 200 sheet. Nothing longer. Charts stay at zero.
Tokens

b · la regla del dim
Dim = modal. The backdrop (black/60 + blur) appears if and only if input focus leaves the page: bottom sheets, dialogs, the FAB quick-capture. It belongs to the overlay, not to any card.
Disclosure never dims. The dashboard hero that darkens the whole page on expand loses its dim; the silent growers gain the caret and label. Both converge on the same idiom — that resolves finding 6 in one rule.
What never moves: no scale on press (hover-tint only), no scroll-triggered motion, no chart animation, no skeleton shimmer choreography. GPU transform/opacity only — grid-rows disclosure is the single sanctioned layout transition.
