6a Zeta · unification layer · T6

Hierarchy for number walls

The rule: one number decides; everything else testifies. A screen may have exactly one number at hero scale — the one that answers ¿voy bien? Enumerations get summarized before they get listed, sorted worst-first, and stripped of repeated alarms: seven rows shouting “SOBRE LIMITE” carry less information than one line saying “7 sobre límite”. State lives once per group; rows carry only their own overage.

V1 RULE The hero number is the derived judgment (112% del plan, cuota total), never the largest raw amount. It is the only number allowed semantic color at scale. SUMMARY FIRST Any group of 3+ same-state rows must be introduced by a V2 summary: count + aggregate delta. The user can stop reading there — the list below is optional proof. STATE ONCE The T1 verdict word appears once per group (in the summary), never per row. Rows show only their own delta in the group’s color. Seven “Te pasaste” chips collapse to one. SORT Worst first, by absolute delta. Healthy groups collapse behind a T3 disclosure (“Ver 10 en orden”) — calm rows should cost a tap, alarm rows should not. BARS Row progress bars are 3px hairlines, track white/6. Only over-limit rows tint their fill debt-red; healthy fills are white/25 — not brass, which would make the wall glitter.
