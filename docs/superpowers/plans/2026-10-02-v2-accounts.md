# v2 accounts (launch PR 3) — plan

**Spec:** `docs/superpowers/specs/2026-10-02-v2-launch-plan.md` §2, interaction spec §6 (S8-4, S8-5), mockup `claude-ai-design/v2-movimientos-acciones/cuentas.html`. Stacked on #446.

## Interfaces
- `AccountRow` (engine): `{ id, userId, name, accountType, institutionName, mask, currencyCode, currentBalance, isActive, creditLimit, cutoffDay, paymentDay, monthlyPayment }`.
- `createAccount { accountId, accountType: CHECKING|SAVINGS|CASH|CREDIT_CARD|LOAN, name, institutionName?, mask? (4 digits), currencyCode, balance, creditLimit?, cutoffDay?, paymentDay?, monthlyPayment? }` — balance is money you have (assets) or owe (debts, ≥ 0). Re-sending the id = duplicate.
- `editAccount { accountId, name?, institutionName?, mask?, creditLimit?, cutoffDay?, paymentDay?, monthlyPayment? }` — per-field versions; `superseded` when nothing changed.
- `archiveAccount { accountId, archived }` — field `is_active`, versioned. Archived accounts leave Mis cuentas and pickers; their movements stay.
- `balanceDelta(accountType, direction, amount)`: assets +in/−out; debts −in/+out (v1 `applyAccountBalanceDelta`). Used by capture/edit/delete/exclude.

## Rulings
- Cuadrar deferred (absolute set vs replayed deltas = ordering problem) → BACKLOG.

- Mis cuentas header shows `balanceToday` from the engine, so it can't disagree with Inicio; onboarding (Oct 12–15) asks per-account balances.
- Debt accounts never count for Disponible (S3-0); their switch isn't shown.
