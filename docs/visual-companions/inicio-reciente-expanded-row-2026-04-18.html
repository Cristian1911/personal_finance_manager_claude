Rules
  • Categorizar — only on OUTFLOW. Brass-tinted when category_id == null, neutral otherwise.
  • Vincular — only shown when the account has pending recurring occurrences AND the tx is not already linked.
  • Más — always shown. Its flex expands to fill when Vincular isn't present.
  • INFLOW rows show a 2-chip layout (Vincular when applicable + Más); no Categorizar.
