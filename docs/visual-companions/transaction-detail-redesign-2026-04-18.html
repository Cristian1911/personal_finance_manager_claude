Layout rules — fully optimistic, no save button
  • Hero — direction pill, merchant title, signed amount, single meta line (date · account · source). Read-only.
  • Clasificación — inline pills. Categoría indigo-tinted when set, muted outline when empty. Destinatario brass-tinted when set, muted outline when empty. Tap pill → Popover (desktop) or Drawer (mobile). Saves optimistically on select + toast.
  • Etiquetas — brass chips with × remove (optimistic). + etiqueta opens the tag picker.
  • Notas — inline-editable textarea. Autosave on blur + toast.
  • Descripción original — collapsed disclosure. Expands in place.
  • Acciones — chip trio: Hacer recurrente (brass-ghost, primary intent) · Vincular (neutral, only when the account has pending occurrences) · ⋯ (opens sheet: Excluir · Eliminar). Fire immediately on tap.

Final direction

Fully optimistic. Every interaction persists immediately — pill select, tag add/remove, notes blur, action tap. Matches the Dashboard row pattern we shipped and avoids the "dirty-state / am-I-saved?" cognitive tax. Toasts confirm each mutation.
